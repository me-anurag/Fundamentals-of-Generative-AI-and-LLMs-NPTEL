# Contributing

Thanks for wanting to help improve this repo.

## How to contribute

1. Fork the repository and create a new branch off `main`.
2. Make your changes inside the relevant `Week-XX` folder, keeping the existing layout:
   - `slides/` for lecture slides and notes
   - `revision/important-concepts.md` and `revision/quick-revision.md`
   - `assignment-solutions/questions.md`, `solutions.md`, and `explanations.md`
3. Keep the formatting consistent with the rest of the repo.
4. If you're introducing a new term or architecture, add a short entry to `resources/glossary.md` as well.
5. Open a pull request with a short description of what changed and why.

## Some guidelines

- Keep notes clear and to the point rather than overly long.
- If you reference a paper or book, add it to `resources/books-and-references.md`.
- Don't upload copyrighted slides, PDFs, or paid course material directly. Link to the official source instead.
- Stick to plain Markdown, no need for special formatting.

## Reporting an issue

If you notice something incorrect or missing, open an issue describing it and it'll get looked at.

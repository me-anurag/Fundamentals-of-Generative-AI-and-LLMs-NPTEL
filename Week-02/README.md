# Week 02: Autoencoders: The First Generative Model

Part of the Fundamentals of Generative AI and Large Language Models: Theory and Practice - NPTEL repository.

## Topics Covered

- What is an autoencoder?
- Encoder-decoder architecture
- Bottleneck representation
- Undercomplete vs overcomplete autoencoders
- Training objective: reconstruction loss
- Denoising autoencoders
- Limitations of autoencoders, motivating VAEs

## Hands-On Exercise

Implement a vanilla autoencoder for the dataset. Add noise and train a Denoising Autoencoder (DAE). Visualize original vs reconstructed images and bottleneck vectors.

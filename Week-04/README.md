# Week 04: Advanced VAEs and Practical Applications

Part of the Fundamentals of Generative AI and Large Language Models: Theory and Practice - NPTEL repository.

## Topics Covered

- Conditional VAE (CVAE)
- Beta-VAE and disentanglement
- Latent space interpolation
- Image generation using VAEs
- Strengths and limitations vs. GANs
- Motivation for adversarial training, leading into GANs

## Hands-On Exercise

Build a Conditional VAE for the dataset. Perform latent traversals to observe disentanglement. Compare VAE vs CVAE outputs for class-controlled generation.

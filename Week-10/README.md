# Week 10: Foundations of Large Language Models (LLMs) and Prompt Engineering

Part of the Fundamentals of Generative AI and Large Language Models: Theory and Practice - NPTEL repository.

## Topics Covered

- What is an LLM?
- Transformer architecture: encoder, decoder, decoder-only
- Self-attention mechanism
- Tokenization: BPE, WordPiece
- Prompt engineering basics

## Hands-On Exercise

Implement a tiny Transformer for next-token prediction. Use HuggingFace to load a small LLM (DistilGPT-2) and generate text. Compare outputs using different sampling methods: greedy, top-k, nucleus.
